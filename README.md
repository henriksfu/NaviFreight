# NaviFreight

Enterprise fleet and yard management system for multi-tenant logistics operations.

## Product Scope

NaviFreight is designed as a SaaS platform for:

- Fleet dispatch and routing visibility
- Yard occupancy and dock scheduling
- Transportation operations monitoring
- Real-time synchronization across tenant fleets
- Operational reporting and analytics

## Repository Structure

- `frontend/` Angular application for the operations dashboard
- `backend/` C# services and solution files
- `database/` SQL schema, stored procedures, and seed scripts
- `infra/` Azure infrastructure and environment templates
- `docs/` architecture, delivery phases, and standards

## Delivery Phases

1. Repository foundation and architecture
2. Angular dashboard shell and test setup
3. C# backend service skeleton
4. SQL schema and stored procedures
5. Azure infrastructure scaffolding
6. Integration and verification
