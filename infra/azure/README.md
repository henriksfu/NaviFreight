# Azure Infrastructure

This folder contains deployment placeholders for NaviFreight environments.

## Initial Targets

- Azure App Service or Container Apps for the API
- Azure SQL Database for transactional data
- Azure Key Vault for secrets
- Azure Application Insights for monitoring

## Environments

- `environments/local/`
- `environments/dev/`
- `environments/prod/`

Infrastructure-as-code templates can be added here once the deployment model is finalized.
